Практические работы по Java, блок N3

Практические работы по дисциплине «Введение в алгоритмы и структуры данных систем реального времени», РТУ МИРЭА. В этом блоке две практики: N9 (сортировка слиянием) и N17 (связные списки).

Каждая папка с заданием это отдельный пакет, например praktika17.task02.

Что в папках
praktika09/task03: слияние двух списков студентов

Программа объединяет два списка студентов в один, отсортированный по номеру студента (iDNumber). Каждый список сортируется сортировкой слиянием, потом два отсортированных списка сливаются в один.

Student.java: студент (номер, фамилия, балл), реализует Comparable
MergeStudents.java: сортировка слиянием и метод mergeLists, который объединяет два списка
MergeTest.java: запуск, два списка на входе и общий отсортированный список на выходе
praktika17: картотека студентов на связных списках

Консольное приложение с текстовым меню: добавить студента, удалить по номеру, показать одного или всех, очистить список, проверить, пуст ли список. Задание сделано три раза, на разных структурах данных:

Папка	Структура данных
task01	односвязный список
task02	двусвязный список (в меню есть вывод с конца)
task03	кольцевой список (в меню есть обход по кругу)

В каждой папке одни и те же четыре файла:

Student.java: элемент картотеки, считывает данные с консоли и выводит их на экран
Node.java: узел списка
StudentList.java: сам список (добавление, удаление, вывод, очистка, проверка на пустоту)
Tester.java: класс с main и меню

Нумерация студентов в меню идёт с 1. Запись списка в файл и чтение из файла не делались, в задании они помечены как необязательные.

Как запустить

В IntelliJ IDEA: открыть папку проекта и запустить main в MergeTest (задание 9) или в Tester нужной папки (задание 17).

Из консоли, из корня репозитория:

javac -encoding UTF-8 praktika09/task03/*.java
java praktika09.task03.MergeTest

javac -encoding UTF-8 praktika17/task01/*.java
java praktika17.task01.Tester

Для task02 и task03 меняется только номер папки.

В коде нет generics и стандартных коллекций: списки и узлы написаны вручную, а студенты хранятся в обычных массивах.
