## Что в папках

### praktika09/task03: слияние двух списков студентов

Программа объединяет два списка студентов в один, отсортированный по номеру студента (`iDNumber`). Каждый список сортируется сортировкой слиянием, потом два отсортированных списка сливаются в один.

- `Student.java`: студент (номер, фамилия, балл), реализует `Comparable`
- `MergeStudents.java`: сортировка слиянием и метод `mergeLists`, который объединяет два списка
- `MergeTest.java`: запуск, два списка на входе и общий отсортированный список на выходе

### praktika17: картотека студентов на связных списках

Консольное приложение с текстовым меню: добавить студента, удалить по номеру, показать одного или всех, очистить список, проверить, пуст ли список. Задание сделано три раза, на разных структурах данных:

| Папка | Структура данных |
| --- | --- |
| `task01` | односвязный список |
| `task02` | двусвязный список (в меню есть вывод с конца) |
| `task03` | кольцевой список (в меню есть обход по кругу) |
